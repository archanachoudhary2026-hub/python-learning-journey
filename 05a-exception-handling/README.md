# Exception handling

One notebook practices safe division, skipping invalid product prices, age validation, file errors and a shopping cart using demo inputs.

Open this folder in Jupyter or VS Code and run the cells in order. Enter integers for division and age. The age exercise keeps asking until it receives a value from 1 to 120. Enter one cart price at a time and use `q` to quit.

The file exercise creates or replaces `example.txt` in the working folder. Use a separate practice copy of the folder. Try `example.txt` to read the sample, or a missing filename to see error handling. No extra libraries are needed.
