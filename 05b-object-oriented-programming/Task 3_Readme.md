# Product Management System - OOP Inheritance Demo

A simple Python application demonstrating Single-Level Inheritance and Method Overriding using standard Object-Oriented Programming (OOP) principles.

## Features

- **Base Class (`Product`)**: Handles core product attributes like name, price, and category.
- **Subclass (`ElectronicProduct`)**: Inherits from `Product` and extends functionality with a warranty tracking attribute.
- **Method Overriding**: The `get_info()` method is overridden in the subclass to display specialized technical details seamlessly.
