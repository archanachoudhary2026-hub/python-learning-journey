# Learning NumPy: Task 1

This project is a simple practice exercise to learn how to create and check arrays using the NumPy library in Python.

## What This Code Does

1. **Imports NumPy**: Brings the NumPy library into Python so we can use it.
2. **Creates 3 Arrays**:
   * A 1D array (a single row of numbers) from 1 to 10.
   * A 2D array (a 3x3 grid/matrix) with numbers from 1 to 9.
   * A NumPy array made from a standard Python list `[10, 20, 30, 40, 50]`.
3. **Prints Information**:
   * Shows what each array looks like.
   * Prints the **shape** (the size and layout) of each array.
   * Prints the **data type** (tells us if they are integers or decimals).

## Helpful Things to Remember

* **`np.arange(1, 11)`**: Generates numbers starting at 1 and stops right before 11.
* **`.reshape(3, 3)`**: Turns a flat line of 9 numbers into a neat 3x3 box grid.
* **Shape output like `(10,)`**: The comma just means it is a simple 1D line of 10 numbers, not a grid.
