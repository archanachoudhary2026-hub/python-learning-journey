# Sales Data Visualization

## Overview
This project demonstrates how to analyze and visualize sales data using Python.  
The dataset is sourced from Kaggle and contains car sales information such as price, dealer region, customer demographics, and dates.  

The goal is to practice data preprocessing with **Pandas** and create different types of plots with **Matplotlib**.

---

## Tasks Implemented


1. **Line Plot** - Monthly sales trend  
2. **Scatter Plot** - Relationship between annual income and sales  
3. **Bar Charts** - Vertical and horizontal bar charts of sales  
4. **Multiple Bar Plots** - Comparison by year, gender, and dealer region  
5. **Stacked Bar Chart** - Monthly sales split by gender  
6. **Histogram** - Distribution of sales amounts  
7. **Pie Chart** - Share of sales records by dealer region  

## Requirements

Install the following libraries:

pip install pandas matplotlib numpy


## How to Run

Open `Sales_Analysis.ipynb` and run its cells in order. The included compressed data file supplies the five analysis columns. No extra dataset download or path change is needed. See [README.md](README.md) for the source, licence and included-data details.

### Visualization

Line, scatter, bar, stacked bar, histogram, and pie charts
